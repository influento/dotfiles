Cheatsheet · common motions

Common vim motions

leader = Space · [count] op [count] motion · doubled op = whole line

  • 2dawdelete two words
  • ci"change inside quotes
  • d3jdelete three lines down
  • gUiwuppercase inner word
  • dt;delete until ;
  • df)delete through )
  • *cgn …Esc . .rename via search + repeat
  • ggVGselect entire file
  • ddpswap line with next

Tmux

prefix p = Ctrl+Space · p X means prefix then X · mouse on · base-index 1 · vi copy-mode

  • p |vertical split
  • p -horizontal split
  • Ctrl+h/j/k/lmove pane (no prefix)
  • p stmux-warp jump (flash-style)
  • p ffzf session switcher
  • p [enter copy-mode
  • v … y(in copy) select + yank
  • p zzoom current pane
  • p :command prompt
